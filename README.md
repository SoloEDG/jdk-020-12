## 机位拖移与换位

停在机位上的飞机可以再次移动，不再是一次性分配。

- **临时等待位**：H01 / H02 是真实占用位置，可停靠但无法开展保障。
- **拖移计划**：选择目标机位后先看到路线、等待原因、作业影响与耗时，再决定是否执行。
- **等待释放**：目标仍被占用时计划保持等待；原机位在拖车挂接前始终占用，绝不提前释放。
- **两机换位**：必须经过中转等待位（对方 → 中转位 → 本机 → 对方进位），不是互换编号。
- **作业影响**：在途车辆跟随到新位置；正在作业的暂停或重新连接；已完成成果只在确实受影响时失效。
- **策略选择**：晚拖移等待在途作业结束、中断更少；立即拖移优先腾空稀缺机位并承担恢复耗时。
- **异常处理**：拖移途中取消会先安全返回原机位；停妥前不恢复保障、不允许推出；拖移期间收到的离港指令会排队。
